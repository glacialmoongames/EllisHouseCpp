# Cover artwork

These files are mechanical format conversions of the two covers supplied with
the project. No generative image was used in the included artwork.

- `original/`: unchanged supplied PNG covers
- `psp/retroflow/EllisHousePSP.png`: 250×320 PNG named for the PSP homebrew
  folder, ready for RetroFlow Launcher
- `gba/standard/IMGS/E/L/ELLI.bmp`: 120×80, 24-bit BMP for the standard
  EZ-Flash Omega/Omega DE kernel
- `gba/ds-style/SYSTEM/IMGS/E/L/ELLI.bmp`: 120×80 wide DS Style art
- `gba/ds-style/SYSTEM/IMGS2/E/L/ELLI.bmp`: 80×80 square DS Style art

See the platform installation guides in `docs/` for the destination paths.
