# Install on Nintendo 3DS

This port is intended for a homebrew-capable Nintendo 3DS. The build supports
the stereoscopic top screen and uses the lower screen for secondary UI.

## Homebrew Launcher (`.3dsx`)

1. Download and extract `EllisHouse-3DSX.zip`.
2. Copy its `3ds/EllisHouse3DS` folder to the `3ds` folder on the SD card.
3. The final path must be `sd:/3ds/EllisHouse3DS/EllisHouse3DS.3dsx`.
4. Start Elli's House from the Homebrew Launcher.

## CIA

1. Download `EllisHouse-3DS.cia`.
2. Copy it anywhere on the console SD card.
3. Install it with the CIA installer already present on the homebrew setup.
4. Launch **Elli's House** from the HOME Menu.

The 3DSX save is written to `sdmc:/3ds/EllisHouse3DS/Save.sav`.
